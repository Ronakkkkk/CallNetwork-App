# 📱 CallNetwork – Decentralized Contact Network & Universal Caller ID

CallNetwork is **DePIN for Trucaller** that empowers users to build a **decentralized phonebook**, protect themselves from spam calls using **ZK (Zero Knowledge) privacy**, and earn rewards for identifying spam contacts.

> A privacy-first alternative to Truecaller – powered by **DePIN** and built on Solana.**Launching on Solana Mobile Soon!**

---

## 💰 Identify spam to earn

- 📞 **Import contacts**  to get $CALL Rewards 
- 🔒 **Get More $Call as you Contribute:** Flag spam, verify, suggest edit
- 🤝 **Refer CallNetwork to your friends and earn $Call**
